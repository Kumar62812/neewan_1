# A2 source-inconsistency register

**Prepared:** 2026-10-28, alongside [A2-v1.0](A2_RESEARCH_SCOPE_FREEZE_v1.0.md)
**Rule:** items here are **recorded, not resolved**. No source document was changed. Anything marked "amendment" needs a dated, versioned amendment (PLAN §12, RP §14) approved by the author before it takes effect.

Source keys: PLAN = `Files/FORMAL_AMBIG_RTL_PLAN.md`; RP = `research_protocol.md`; BS = `benchmark_schema.md`; FVP = `formal_verification_protocol.md`; AP = `annotation_protocol.md` (the last four are in `Files/Research_Papers/docs/`); GOV = `docs/project-sequence/` author governance.

**Priority** says when the item must be settled:
- **Before T08:** affects the reusable case template.
- **Before Gate 3:** must be settled before cases are certified.
- **Before Gate 4:** must be settled before scored LLM experiments.
- **Record only:** documentation or naming issue with no effect on results.
