# Legacy / Imported Material

This directory is a provenance-preserving holding area for material that is retained for historical reference but is not part of the active FORMAL-AMBIG-RTL evidence chain.

## Rules

- Nothing here is deleted merely because it is legacy.
- Historical provenance is preserved by retaining original blob contents and recording the original path in curation manifests where practical.
- Legacy material must not be cited as active benchmark evidence unless an explicit provenance record says so.
- Accepted formal evidence remains outside this area when moving it would create provenance ambiguity.
